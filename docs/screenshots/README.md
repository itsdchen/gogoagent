# Screenshot assets

`overview.png` and `launcher.png` are generated by:

```bash
corepack pnpm screenshots:demo
```

The script captures the real Electron UI using a temporary home directory,
fictional repositories and transcripts, a fake `claude` executable waiting at
a choice prompt, and an isolated sidecar port. It exercises the real terminal
and attention indicator but does not invoke Claude or use an account. Do not
replace these files with screenshots from a normal gogoagent session.

Before committing regenerated images, inspect them for:

- usernames or absolute home paths;
- real repository, branch, or workstream names;
- real transcript or terminal content;
- unrelated desktop chrome or notifications.
